# 接口说明

> 全部服务只绑定 `127.0.0.1`，不监听局域网、不接受外部连接。

## 端口

| 服务 | 默认端口 | 说明 |
|---|---|---|
| 静态网页版 | 3759（备用 3763） | 浏览器打开 `http://127.0.0.1:3759/` |
| 控制通道 | 3757（备用 3761） | WebSocket，用于本地调试/自动化 |
| MCP | 8768 | Streamable HTTP，`/mcp` |

端口被占时会自动换到备用端口，实际端口见运行日志或「关于」窗口。

## 安全边界

1. **只绑本机**：三个服务都 `listen(端口, '127.0.0.1')`，局域网和外网无法访问。
2. **来源校验**：控制通道校验 `Origin`；MCP 对带 `Origin` 且非本机页面的请求直接 403。
3. **媒体类型校验**：MCP 的 POST 只接受 `application/json`，
   挡掉 `text/plain` / 表单这类可绕过浏览器预检的「简单请求」。
4. **静态服务白名单**：只提供 `index.html` 与 `js/ lib/ models/ strings/ recipes/ build/`，
   `desktop/`（主进程源码）、`node_modules/`、`package.json`、日志与 `*.jsonl` 一律 404。
5. **无鉴权但有边界**：本机任何程序都能调用这些接口。如果多人共用一台机器，
   请用系统账户隔离；不要把端口转发到公网。

## MCP

- 地址：`http://127.0.0.1:8768/mcp`
- 协议：JSON-RPC 2.0 / MCP（`initialize`、`tools/list`、`tools/call`、`ping`）
- 工具：12 个（表情、动作、配方、说话、状态、能力表等）

示例：

```powershell
$body = '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_state","arguments":{}}}'
Invoke-RestMethod -Uri 'http://127.0.0.1:8768/mcp' -Method Post `
  -ContentType 'application/json' -Body $body
```

## 控制通道

WebSocket `ws://127.0.0.1:3757`，发送 JSON 指令：

```json
{"action":"expression","name":"shy"}
{"action":"motion","group":"默认手切举手"}
{"action":"bubble","text":"……","dur":2000}
```

隐藏调试指令（仅本地 WS，不对外暴露）：

| 指令 | 作用 |
|---|---|
| `_shot` | 截一张窗口图到 `%APPDATA%\nono-live2d-desktop` |
| `_interactive` | 切换「可点击 / 穿透」 |
| `_zones` | 导出分区网格到 `touch.jsonl` |
| `_touchall` | 直接触发「摸遍全身」害羞表演 |

## 静态网页版

`http://127.0.0.1:3759/`，与桌面版共用同一套模型与行为层。

## 关闭接口

不需要对外接口时，可以只运行 exe 不调用任何端口；这些服务只在本机内部使用，
不影响桌宠本身的全部功能。
